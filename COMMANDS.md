# Commands

## `/tokens` — Show Token Usage

Display daily, weekly, and monthly token usage with costs.

### Format

```
/tokens
```

### Response

```
📊 **Token Usage Breakdown**
🤖 **Model:** Claude Haiku 4.5 ($1.00/M in, $5.00/M out)

**TODAY (live):**
   Input: 36 | Output: 448 | Total: 484 | Cost: $0.0022

**WEEKLY (last 7 days):**
   Input: 58 | Output: 707 | Total: 765 | Cost: $0.0035

**MONTHLY (last 30 days):**
   Input: 58 | Output: 707 | Total: 765 | Cost: $0.0035

📁 History stored in: /home/openclaw/.openclaw/workspace/token-history
Generated by bash (0 tokens)
```

### Handler

```
/home/openclaw/.openclaw/workspace/git-repos/openclaw-token-tracker/tokens-command.sh
```

### Cost

~$0 (pure bash, no LLM calls)

### Setup

Make sure `daily-token-counter.sh` and `token-history-logger.sh` are in workspace and cron is configured:

```bash
55 23 * * * /home/openclaw/.openclaw/workspace/token-history-logger.sh >/dev/null 2>&1
```
